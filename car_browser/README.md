# 车机专属云端纯浏览器 (方案四 · 独立容器)

本目录为独立车机串流浏览器服务，**与根目录的 `juchang8` 核心业务服务完全隔离解耦**：
- 独立的 `docker-compose.yml`
- 独立的 `./data` 配置与缓存目录
- 独立的端口 (`3000`)
- 独立的启停脚本 (`./start.sh` 和 `./stop.sh`)

无论是拉取、更新、启动、重启还是停止，都绝不影响 `juchang8` 的稳定运行。

---

## 快速使用

### 1. 启动服务
在服务器进入本目录执行：
```bash
cd car_browser
./start.sh
```

### 2. 车机访问
在车载浏览器打开：
```
http://<你的服务器IP或DDNS>:3000/
```
*(如：`http://hackjown.3322.org:3000/`)*

## 工作原理解析
1. **云端原生解码**：Chromium 运行在服务器 Docker 容器内，具备标准的 H.264/AAC 解码器与完整的视音频同步主时钟，电影/短剧在容器内原生播放，**唇形与声音绝对同步，永不漂移**。
2. **KasmVNC 增量串流**：通过单端口 `3000` 将画面（Canvas 增量重绘）与声音（Web Audio 流）推送给车机，比传统的 MJPEG 节省 70%~80% 带宽，**彻底消灭微卡顿**。
3. **100% 免疫行车拦截**：车机端接收到的仅仅是一个普通的 HTML5 `<canvas>` 画布，车机安全守护进程（检测 `<video>` 标签或 MediaCodec 驱动的机制）完全无法抓取到任何视频特征，行车看剧畅行无阻。
4. **全屏 Kiosk 沉浸体验**：开机自动以全屏 Kiosk 模式载入剧场8/看剧系统，隐藏所有浏览器框架与地址栏，车机屏幕直接全屏点选看剧。

## 自定义启动网页 (可选)
默认打开本地的看剧页面 `http://host.docker.internal:8077/car`。

如果想让车机浏览器启动时默认打开其他第三方电影网站，或者特定的地址，可以在当前目录下创建 `.env` 文件指定 `CAR_URL`：
```bash
echo 'CAR_URL=https://www.example.com' > .env
./start.sh
```

---

## 停止服务
```bash
cd car_browser
./stop.sh
```
